# 待補截圖

把截圖放進這個 assets/ 資料夾，然後到 README.md / CONTRIBUTIONS.md 把對應的
`[截圖：...]` 那行換成正式圖片語法，例如：

    ![CCND 概念網路圖](assets/ccnd-graph.png)

建議檔名與內容：

| 檔名 | 拍什麼 |
|---|---|
| ccnd-graph.png | CCND 概念網路圖，對話進行到一半、已長出多個節點、看得出層次 |
| home.png | 首頁，議題卡片與進入對話的入口 |
| settlement.png | 對話結算頁，立場前後變化 |
| achievement.png | 成就頁的成就牆（能同時拍到解鎖 toast 更好）|
| knowledgebase.png | 知識庫首頁，觀點卡片或議題列表 |
| godot-lobby.png | 虛擬大廳世界全景，地圖與角色 |
| godot-issue.png | 角色頭頂的議題泡泡與表情列 |

動態的話用 GIF 更好（例如大廳走動互動、CCND 長出來的過程）。每張壓到 1MB 以內。
