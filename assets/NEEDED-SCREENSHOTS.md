# 待補截圖清單

把截圖放進這個 `assets/` 資料夾，檔名照下面。放好後，去 README.md / CONTRIBUTIONS.md 把對應的
`> 🖼️ _[截圖位：...]_` 那行換成正式圖片語法，例如：

```markdown
![對話結算](assets/settlement-receipt.png)
```

## 清單（依重要性排序）

| 檔名 | 拍什麼 | 用在 |
|---|---|---|
| `settlement-receipt.png` | 結算收據頁（立場軌跡 + 雷達 + 甜甜圈）| README, CONTRIBUTIONS Case 1 |
| `ccnd-graph.png` | CCND D3 力導向圖（展開、看得出層次）| README, CONTRIBUTIONS Case 2 |
| `godot-lobby.png` | Godot 世界全景（有玩家）| README, CONTRIBUTIONS Case 3 |
| `godot-issue.png` | 頭頂議題泡泡 + 5 種表情列 | CONTRIBUTIONS Case 3 |
| `settlement-envelope.png` | 結算信封（開封前）| README, CONTRIBUTIONS Case 1 |
| `achievement.png` | 成就牆 + 解鎖 toast | README |

## 加分（GIF 更好，動態最能展現前端/遊戲）

| 檔名 | 拍什麼 |
|---|---|
| `settlement-share.gif` | 信封 → 開封動畫 → 收據 → 按分享匯出 |
| `ccnd-timeline.gif` | CCND 時間軸回放 |
| `godot-letterbox-before-after.png` | 黑邊 → 填滿 前後對比（Case 4 除錯故事）|

> 小技巧：GIF 可用 ScreenToGif（Windows）錄。單張 PNG 直接截圖即可。
> 圖檔盡量壓到每張 < 1MB，README 載入才快。
