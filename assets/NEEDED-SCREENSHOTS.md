# 待補截圖

放進這個 `assets/` 資料夾，檔名照下面。放好後把 README / CONTRIBUTIONS 裡的 `🖼️ assets/xxx.png`
換成 `![說明](assets/xxx.png)`。

| 檔名 | 拍什麼 |
|---|---|
| `ccnd-graph.png` | CCND D3 力導向圖（展開、看得出層次）|
| `godot-lobby.png` | Godot 世界全景（有玩家）|
| `godot-issue.png` | 頭頂議題泡泡 + 表情列 |
| `godot-letterbox-before-after.png` | （可選）黑邊 → 填滿 前後對比 |

GIF 更好（動態最能展現）：`ccnd-timeline.gif`（時間軸回放）、`godot-demo.gif`（大廳互動）。
單張 PNG 直接截圖；GIF 用 ScreenToGif。每張壓 < 1MB。
